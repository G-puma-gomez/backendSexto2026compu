## Acceso de administrador

El administrador inicia sesión con un empleado que tenga el permiso `Administrador`
y una cuenta de acceso asociada en la base de datos. No se necesitan variables
`ADMIN_*` en Render. Configura en Render las variables `DB_HOST`, `DB_NAME`,
`DB_USER`, `DB_PASSWORD` y `DB_PORT` para que el backend use la base de datos
que contiene los registros.
